# 常见问题

## Nexly API 可以直接使用 OpenAI SDK 吗？

可以。把 SDK 的 Base URL 修改为 `https://nexlycn.guangnian.xin/v1`，并使用 Nexly API Key 即可。

## 为什么示例模型无法调用？

文档中的模型名称仅用于演示。调用 `GET /v1/models` 或登录控制台查询你的账号当前可用模型。

## API Key 应该放在哪里？

放在服务端环境变量或密钥管理服务中。不要提交到 Git，不要写入公开网页，也不要打包进客户端应用。

## 为什么返回 401？

检查请求头是否为 `Authorization: Bearer YOUR_API_KEY`，注意 `Bearer` 后有一个空格，并确认 Key 没有被删除或复制不完整。

## 为什么返回 429？

可能是请求频率超过限制、并发过高、账号额度不足或上游渠道限流。请查看错误消息和控制台用量后再决定是否重试。

## 支持流式输出吗？

支持流式输出的模型可以在请求中设置 `"stream": true`。不同模型的能力以实际可用情况为准。

## 在线调试会保存 API Key 吗？

API Reference 可以在当前浏览器中保存认证状态，方便连续测试。请不要在公共或共享设备上使用长期密钥；测试完成后清除认证信息。
